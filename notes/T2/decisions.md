# Decisions

The public id is sha256 of `plainden-policy:v1:${userId}:${kind}`, first 32 hex characters. The row id is that same value. A refresh republishes the same path. A form-minted uuid and a localStorage id were rejected because a refresh or a cleared key would mint a second URL.

The clause body is `lead + answer + trail`. A token inside a sentence was rejected because a missing token can drop an answer.

PDF and Markdown check the plan inside the download function. There is no limit kind for a file. The check is bypassable. The server gate is the hosted row.

Free text and HTML end with `made with plainden`. Every output includes `This draft is not legal advice.`

The stored body is the rendered prose. The public page does not render the catalog again.

Both configs import one `legalLimits` object because `limitsFor` uses the first `legal` row and `cookie-refund` sorts first.

The browser proof opens Image tools for the planned placeholder. Privacy is a real tool, so that drive no longer looks for the old sentence.
