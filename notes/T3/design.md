# PDF tool shape

Subagents could not start. The error was on-demand usage required. Two shapes were compared here, and the first one was built.

The operation is a slug prefix: merge, split, compress, or jpg. runPdf takes that operation, the file bytes, a page range, and a JPEG encoder. The page calls gatePdf before runPdf. The day count lives in one localStorage key.

A second shape, four separate tool components, was rejected. Each one would have copied the limit check and the download step.

The public calls are runPdf, opForSlug, gatePdf, and pageNote. PDF object walking stays inside the engine module.
